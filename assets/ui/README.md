# Original interface assets

`adventurers.png` in `portraits/` is an original, AI-generated painted fantasy portrait atlas created for Hearthtable. It contains four generic archetypes; user-imported portraits take precedence. It does not use BG3 characters, logos or extracted game artwork.

`art/build_chronicle_ui.py` creates the original sculpted-bronze, leather, gem and codex SVG materials. Run it after the older spell/weapon illustration generator when recreating the complete art set. The interface takes broad fantasy-CRPG inspiration while retaining Hearthtable's own assets and 2014 rules.
